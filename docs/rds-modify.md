# Modifying an RDS Instance

You can modify an existing RDS instance to scale its resources or change its configuration.

## Modifiable Attributes
- **Instance Class**: Change the CPU and RAM capacity.
- **Allocated Storage**: Increase the storage size.
- **Security Groups**: Update the network access rules.
- **Backup Window**: Change the timing of automated backups.

> [!WARNING]
> Some modifications may require a reboot, causing a temporary service interruption.
