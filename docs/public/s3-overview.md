# S3 Overview

S3 is a scalable object storage service designed for storing and retrieving files of any size.

## What is S3?

S3 allows you to store files (objects) inside containers called buckets. It is designed for high durability and availability.

## Key Features

- Unlimited storage capacity
- High durability (multi-zone replication)
- Secure access via API keys
- Fast retrieval for frequently accessed data

## Common Use Cases

- File uploads (images, videos, documents)
- Static asset hosting
- Backup and archival storage
