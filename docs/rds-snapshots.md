# RDS Snapshots

Snapshots are point-in-time backups of your database instance.

## Managing Snapshots
- **Manual Snapshots**: Create a snapshot at any time for long-term retention.
- **Automated Backups**: RDS automatically performs daily backups based on your configuration.
- **Listing Snapshots**: View all available snapshots for an instance.
- **Deleting Snapshots**: Remove old or unnecessary snapshots to save storage space.
