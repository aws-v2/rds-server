# Creating an RDS Instance

Learn how to create and configure a new RDS database instance.

## Steps to Create
1. **Choose a Database Engine**: Select the underlying database technology.
2. **Specify Instance Details**: Select the instance class (CPU, RAM) and allocated storage.
3. **Configure Settings**: Set the database identifier, master username, and password.
4. **Network & Security**: Choose the VPC and security groups for your instance.
5. **Review and Launch**: Verify your settings and create the instance.
